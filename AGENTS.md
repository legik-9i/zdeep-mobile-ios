## Общие правила из shared-ai/AGENT_RULES.md

Эти правила действуют во всех проектах; явно указанные ниже проектные исключения сохраняются.

- Спецификации пиши на русском языке, планы — на английском.
- Для актуальной технической документации библиотек и фреймворков используй Context7. Соблюдай более точный порядок источников, если он задан правилами проекта.
- В native-разработке и `subagent-driven-development` по умолчанию поручай написание и исправление кода Luna High, обычное ревью — Terra medium. Если то же замечание повторяется после исправления Luna, поручай Sol выяснить причину и внести узкое исправление; Luna проверяет его тестами. После завершения задачи с планом более чем на три задачи поручай Sol high review. Astra не используй без явного запроса.
- Не взаимодействуй с GitHub: не выполняй удалённые GitHub-операции (`fetch`, `push`, `pull`, clone из GitHub), GitHub API/CLI или создание PR. Работай локально. Если план содержит GitHub-шаг, пропусти его и укажи это в отчёте.
- Новые skills создавай внутри репозитория в `.codex/skills`.
- После архитектурной спеки, созданной через brainstorming, предложи пользователю выбрать между самостоятельной проверкой и проверкой сильным субагентом Sol.
