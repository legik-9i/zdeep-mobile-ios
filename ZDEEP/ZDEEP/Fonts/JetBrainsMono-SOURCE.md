# JetBrains Mono

Приложенные статические TTF взяты из официального репозитория JetBrains Mono, релиз `v2.304`:

- `JetBrainsMono-Regular.ttf` — PostScript name `JetBrainsMono-Regular`.
- `JetBrainsMono-Medium.ttf` — PostScript name `JetBrainsMono-Medium`.
- `OFL.txt` — лицензия SIL Open Font License 1.1.

Обе гарнитуры содержат кириллицу и символы диагностического кода экрана. WebView продолжает использовать свой установленный пакет `@fontsource/jetbrains-mono`.

Источник: https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf
