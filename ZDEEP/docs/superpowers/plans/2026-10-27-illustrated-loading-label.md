# План реализации: убрать подпись с иллюстрированного экрана загрузки

> **Для исполнителей:** выполнять план самостоятельно в текущей сессии; шаги отмечаются чекбоксами.

**Цель:** убрать видимую подпись «Загрузка» с полноэкранного экрана подготовки веба с картинкой.

**Архитектура:** изменить только `WebLoadingView`, не трогая `NativeLoadingView`. Обновить существующие UI-тесты, которые уже доходят до иллюстрированного экрана, затем удалить только текст.

**Стек:** SwiftUI, XCTest UI tests, `scripts/zdeep.py`.

**Спецификация:** `docs/superpowers/specs/2026-10-27-illustrated-loading-label-design.md`.

## Общие ограничения

- Обычный экран `NativeLoadingView` сохраняет подпись «Загрузка».
- Полноэкранная картинка и ThinkingOrb остаются без изменений.

## На что обратить внимание

- На обычном экране ожидания подпись остаётся; это проверяет существующий общий UI-тест загрузки.

### Задача 1: убрать текст с иллюстрированного экрана

**Файлы:**
- Изменить: `ZDEEP/ZDEEPUITests/AuthorizationUITests.swift`
- Изменить: `ZDEEP/ZDEEP/Presentation/WebLoadingView.swift`

**Интерфейсы:**
- Используется: существующий идентификатор доступности `webLoadingScreen` и тестовый сценарий авторизации через QR.
- Результат: иллюстрированный экран остаётся видимым без «Загрузка»; обычный экран ожидания не меняется.

- [x] **Шаг 1: написать падающие тесты**

Обновить `test_syntheticQrStartsSingleRegistrationWithoutLoadingUnlinkAction` и `test_coldRestoreLoadingHasNoUnlinkAction`: ждать `webLoadingScreen` и проверять отсутствие `app.staticTexts["Загрузка"]`.

- [x] **Шаг 2: проверить ожидаемое падение**

Запустить каждый из тестов отдельно командой `python3 scripts/zdeep.py test --environment local --suite ui --only 'ZDEEPUITests/AuthorizationUITests/<имя-теста>()' --simulator 0DDEE416-EECF-4BF3-8F15-BA93A980033A`.

Ожидание: иллюстрированный экран найден, затем проверка отсутствия «Загрузка» падает, потому что текущий экран показывает эту подпись.

- [x] **Шаг 3: внести минимальную правку**

Удалить `Text("Загрузка")` и его оформление из `WebLoadingView`; оставить картинку, ThinkingOrb и верхний отступ.
