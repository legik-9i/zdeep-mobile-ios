# План реализации нативного welcome

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить технический стартовый экран светлым welcome по Stitch, сохранив инфраструктуру через Debug-панель.

**Architecture:** Отдельный WelcomeView отвечает за композицию и использует общие стили и локальные ресурсы. ContentView переключает welcome и существующий WebView, сохраняя координатор и диагностику. DebugPanel получает команды открытия и закрытия WebView.

**Tech Stack:** SwiftUI, UIKit/CoreText для проверки шрифтов, Asset Catalog, существующий XCTest и scripts/zdeep.py. Новые сторонние runtime-зависимости не нужны.

**Spec:** Согласованный в этой беседе ограниченный дизайн, принятый пользователем словом «принимаю». Отдельный архитектурный spec не требуется. Обязательные требования и уточнения полностью сохранены ниже.

## Global Constraints

- Только вертикальный iPhone; минимальная версия приложения iOS 17.6. App target и test targets должны иметь согласованные deployment targets.
- Светлая тема конкретного Welcome (`Bento Grids`), screen ID `bc93291bf18e4d78b737a9a035b30434`, project ID `1417382377358815087`. HTML: `/tmp/native-welcome.html`; перед реализацией сохранить копию в рабочие материалы плана. Не открывать браузер.
- Hero — только изображение. Заголовок, описание и две кнопки составляют единый нижний блок. На высоких экранах растёт промежуток между картинкой и нижним блоком.
- Контент учитывает safe area, фон покрывает весь экран. Нижний внешний отступ брать из `pb-8` HTML, добавляя его внутри safe area, а не заменяя им системный inset.
- Изображение полностью видно, его высота определяется шириной и отношением 1672:941. Оригинал: `/Users/oleg/Downloads/สแกน QR ในรถยนต์ไฟฟ้า.png`. Подготовить оптимизированные варианты разрешений, не разбивать сцену на части и не генерировать заново.
- Inter во всём welcome, включая описание; локальные TTF/OTF, реальные веса, кириллица, Dynamic Type. WebView использует Inter 400/500/600/700, источник `/Users/oleg/projects/zdeep-webview2/src/styles/index.css`. Не менять веб-репозиторий.
- Надписи: «ZDEEP», «Подключите ваш Zeekr», «Отсканируйте QR-код на экране автомобиля, чтобы подключить Zeekr к ZDEEP», «Сканировать QR-код», «Как подключить автомобиль».
- Действия welcome-кнопок пустые; без QR-сканера, запросов разрешений и серверных интеграций. Сохранять семантику Button и доступные подписи.
- Иконки молнии и QR воспроизвести по SVG HTML. Help — исходный Material Symbols Outlined help_outline, не заменять произвольным похожим символом.
- При нехватке высоты вся композиция доступна через прокрутку; не обрезать текст и не уменьшать размер шрифта ради размещения.
- Debug доступен в DEBUG, команды WebView переносим туда. Release показывает чистый welcome; инфраструктуру координатора и USB-диагностики сохраняем.
- Разработка — Luna (`gpt-6-luna`), все ревью — Sol (`gpt-6.1-sol`). Повторяющееся замечание после исправления Luna передаётся Sol для узкого исправления без запуска проверок; затем Luna проверяет результат. Astra не использовать.
- Не выполнять сетевых обращений к prod. Изменения делать в отдельной ветке/рабочем дереве; исходные незакоммиченные настройки пользователя сохранить.

## Review Focus

- Компактный iPhone и увеличенный текст: все надписи и кнопки доступны, без наложений и обрезания.
- Высокий iPhone: нижний блок остаётся у нижней safe area; картинка сохраняет пропорции.
- Регистрация шрифтов: настоящие Inter-веса и кириллица без незаметной подмены системным шрифтом.
- Debug/WebView: открыть, закрыть и повторно открыть сессию можно после удаления старого стартового UI.
- Release и конфигурация: нет технических кнопок на welcome, сохранены пользовательские настройки и портретный iPhone.
