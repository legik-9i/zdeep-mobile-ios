# Убрать подпись с иллюстрированного экрана загрузки

- **Задача:** убрать видимый текст «Загрузка» с экрана `WebLoadingView`, где полноэкранная картинка сочетается с ThinkingOrb; сохранить эту подпись для VoiceOver как доступное имя спиннера.
- **Не входит:** обычный `NativeLoadingView` без картинки сохраняет свою подпись; поведение спиннера и переходы экранов не меняются.
- **Подходы:** можно убрать подпись только у иллюстрированного экрана или с обоих экранов ожидания. Выбран первый вариант, потому что он соответствует запросу и не меняет другие состояния приложения.
- **Проверка:** UI-тест подтверждает отсутствие подписи на иллюстрированном экране; существующие проверки обычного экрана ожидания остаются актуальными.
- **Решение реализации:** удалить текстовый элемент из `WebLoadingView`, назначить ThinkingOrb доступную подпись «Загрузка» и сохранить картинку.
