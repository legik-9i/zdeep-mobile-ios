# Исходники брендинга ZDEEP Mobile

Предоставлены пользователем 2026-10-04. Сохранены без изменения изображения, размер каждого — 1024×1024.

- [Вариант с белым фоном](ZDEEP_Mobile_1024_white.png) — исходник иконки приложения.
- [Непрозрачная RGB-копия](ZDEEP_Mobile_1024_icon.png) — вариант для AppIcon, созданный детерминированным композитингом на белый фон; исходное RGB-содержимое сохранено пиксельно.
- [Прозрачный вариант](ZDEEP_Mobile_1024_transparent.png) — исходник логотипа для Launch Screen и стартового состояния.

Стартовый фон совпадает с фоном приветствия и остальных нативных экранов приложения. Используем существующий цвет `WelcomeStyle.background` (сейчас `#F5F5F7`); Launch Screen и стартовое состояние имеют одинаковый фон. Итоговые размер логотипа и отступы определяются при подготовке экрана. Эти файлы пока не подключены к каталогу ресурсов приложения.
